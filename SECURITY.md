# Security policy

Report a vulnerability in the Silo Roku app privately, through GitHub's
[private vulnerability reporting](https://github.com/Silo-Server/silo-roku/security/advisories/new).
Do not open a public issue, pull request, or discussion for it.

Include the Roku model and Roku OS version, the app version (Settings), the
Silo server version, and the steps that show the problem. Leave out access
tokens, passwords, PINs, device-login codes, signed stream URLs, and your
server's address; we will ask for anything else we need.

A problem in the Silo server itself belongs in the
[silo-server](https://github.com/Silo-Server/silo-server) repository.

Only the latest release is supported.
